Use the browser shared by your host

How to connect

Your host handles the browser setup.

  • Open this app. You do not need to install developer tools or Docker.
  • Ask your host to start the browser and send you an Invitation Code.
  • Paste the code above and click Connect.
  • Once the host approves, you can browse freely without touching their computer.
  • Different networks: Your host selects Internet sharing. No VPN or extra installation is needed on your PC. Use version 1.1.0 or later on both PCs.
